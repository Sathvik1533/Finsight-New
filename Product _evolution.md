## 🔥 IDEA-001 — Category Spend Intelligence (Core UX Upgrade)

**Status:** Proposed
**Priority:** High
**Impact:** UX + Insights + Retention

### Description

Provide users with **real-time category-wise total spending** along with **percentage contribution**.

### Features

* Category totals (₹ spent per category)
* Percentage contribution (e.g., Food = 42%)
* Monthly aggregation (live + end-of-month summary)
* Dynamic updates after every receipt upload

### Why It Matters

* Moves from **data display → financial clarity**
* Helps users understand *where money actually goes*
* Creates a strong daily-use loop

## 🔥 IDEA-002 — Engagement-Based Unlock System (Growth Mechanism)

**Status:** Proposed
**Priority:** High
**Impact:** Retention + Monetization

### Description

Unlock features based on **user activity**, not just payment.

### Example Unlocks

* 3 receipts → basic insights unlocked
* 6 receipts → category analytics unlocked
* 10 receipts → decision engine preview
* consistent usage → deeper insights

### Why It Matters

* Builds habit before monetization
* Users experience value before paying
* Reduces churn and increases engagement
